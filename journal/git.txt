HOW TO GIT
----------

Small reminder for me

SAVING PROGRESS WHILE YOU WORK
------------------------------
Select files, commit message, commit, and push.

READY FOR LIVE
--------------

git checkout master
git merge --no-commit work-in-progress
git push origin master

Then return back into the working branch

git checkout work-in-progress

Or to copy master to work-in-progress

git merge --no-commit master

SEE WHAT BRANCH UR ON
---------------------

git branch
